# Product app (Expo)

Web-first React Native student app: auth, highlights feed, practice, dashboard, submissions.

From the repo root:

```bash
pnpm dev:app
```

Or `pnpm --filter @comm-platform/app web` to open the web target directly (`http://localhost:8081`).

Copy `apps/app/.env.example` to `apps/app/.env`. Set `EXPO_PUBLIC_USE_MOCK_API=true` to explore without the Next.js API. See the root `README.md` and `CODING.md` in this folder for setup.
